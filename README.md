# Uzay Simülasyonu

Bu proje, C programlama dili ile geliştirilmiş eğlenceli bir fizik simülatörüdür. Kullanıcının girdiği tek bir değeri (örneğin kütle veya süre) kullanarak, Güneş Sistemi'ndeki 8 farklı gezegende sonucun nasıl değiştiğini hesaplar ve listeler.


**Ne İşe Yarar?**

Dünya'da yaptığınız basit bir fizik deneyinin (örneğin elinizdeki topu yere bırakmak), Jüpiter'de veya Mars'ta nasıl sonuçlanacağını merak ettiniz mi? Bu program size tam olarak bunu gösterir.

Program şu 9 farklı deney yapabilir:

1. Serbest Düşme (Bir cismin düşme mesafesi)

2. Yukarı Atış (Cismin çıkabileceği yükseklik)

3. Ağırlık Hesaplama (Farklı gezegenlerde kaç kg hissedersiniz?)

4. Kütleçekimsel Potansiyel Enerji

5. Hidrostatik Basınç

6. Arşimet Kaldırma Kuvveti

7. Basit Sarkaç Periyodu

8. Sabit İp Gerilmesi

9. Asansör



**Nasıl Çalışır?**

Program açıldığında kendinizi tanıtırsınız (İsim girişi).

Karşınıza gelen menüden yapmak istediğiniz deneyi seçersiniz (1-9 arası).

Program sizden gerekli bilgiyi ister (Örneğin: "Cismin kütlesi kaç kg?").

Girdiğiniz değere göre Merkür'den Neptün'e kadar tüm gezegenler için hesaplama yapılır ve yan yana kıyaslamalı bir tablo oluşturulur.


**Teknik Özellikler**

Bu proje, C programlama dilini öğrenirken aşağıdaki kavramları pekiştirmek için hazırlanmıştır:

Pointer (İşaretçi) Kullanımı: Verilere bellek adresleri üzerinden erişim.

Diziler (Arrays): Gezegen verilerinin tutulması.

Döngüler: Menü sisteminin sürekliliği.


**Kurulum**

Kodu bilgisayarınızda çalıştırmak için herhangi bir C derleyicisi (GCC gibi) yeterlidir.
